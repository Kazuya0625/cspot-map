# 要件定義書

## 1. サービス概要

C Spot Mapは、日常に少し退屈している人が、
身近にある不思議でシュールな「C級スポット」を発見・共有できる地図アプリです。

## 2. サービスの目的

有名な観光地ではなく、
普段なら見過ごしてしまうような場所を見つけることで、
日常に小さな寄り道と発見を提供します。

## 3. 想定ユーザー

- 変化のない日常に少し退屈している人
- 散歩や寄り道が好きな人
- 不思議な場所やシュールなものが好きな人
- 有名観光地ではない場所を探したい人

## 4. C級スポットの定義

以下のような、思わず二度見したり、少し笑ってしまったりする場所を対象とします。

- 謎のオブジェ
- 不思議な石像
- 珍しい看板や標識
- 昭和感の残る場所
- 「なぜここにあるのか」と感じるもの
- 地域独特の小さな見どころ

## 5. Ver.1.0の機能

### 地図表示

- 地図を表示できる
- 登録済みスポットを地図上のピンで確認できる
- ピンを選択してスポットの概要を確認できる

### スポット閲覧

- スポットのタイトルを確認できる
- スポットの写真を確認できる
- スポットの説明を確認できる
- スポットの位置を確認できる

### スポット投稿

- スポット名を入力できる
- 説明を入力できる
- 写真を1枚投稿できる
- 地図上で位置を指定できる

## 6. Ver.1.0では実装しない機能

- ユーザー登録・ログイン
- コメント
- いいね
- お気に入り
- ランキング
- 通知
- 複数画像の投稿

これらは今後のバージョンで検討します。

## 7. 投稿禁止対象

- 個人宅
- 私有地への侵入を促す場所
- 危険な場所
- 廃墟への不法侵入を促す投稿
- 個人や店舗への誹謗中傷
- 正確な位置を公開すると問題がある場所

## 8. 非機能要件

- スマートフォンから利用しやすいこと
- 月額運用費を5,000円以内に抑えること
- 投稿された画像を安全に保存できること
- 障害やエラーを確認できること
- 将来的に利用者が増えても構成を拡張できること
